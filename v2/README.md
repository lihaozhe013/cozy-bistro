# Cozy Bistro 3D (Separate Track)

This directory contains the older Three.js + SpacetimeDB multiplayer-oriented
track. It is retained for reference and independent experiments.

It is not the canonical implementation covered by the root [`SPEC.md`](../SPEC.md)
and should not be treated as a dependency of the root 2D game. The plans and
audits under `v2/` apply only to this track.

Run it from the repository root with:

```bash
pnpm dev:v2
```
